=======================================================
TALIA CUSTOM LYRICS FONTS
=======================================================

You can customize the desktop lyrics font by placing any .ttf or .otf font file in this folder!

Instructions:
1. Drop your font file here (e.g. Arial.ttf, BebasNeue.otf, Montserrat-Bold.ttf).
2. Talia will automatically detect and apply your custom font to desktop lyrics.
3. If this folder is empty, Talia will use the clean default system font.
